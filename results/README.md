# Lokale Ergebnisberichte

Dieses Verzeichnis enthält bei einer lokalen Untersuchung ausführliche Status-,
Evidenz- und Entscheidungsberichte. Diese können Gerätekennungen, Netzadressen oder
private Laufzeitinformationen betreffen und werden nicht mit Git versioniert.

Die für das Repository zusammengefassten Ergebnisse stehen in
[`docs/RESEARCH.md`](../docs/RESEARCH.md). Bestehende lokale Berichte werden durch
die Git-Vorbereitung nicht gelöscht.
